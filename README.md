## Featured Engineering Projects

### Brain Tumor Detection & Diagnosis System
* Built an end-to-end deep learning framework utilizing localized segmentation and a Dilated CNN architecture for accurate classification and detection from MRI imaging.
* Designed low-latency model optimizations allowing efficient deployment on edge hardware constraint systems (Raspberry Pi) for low-resource environments.
* *Stack:* Python, PyTorch, OpenCV, Raspberry Pi.

### Automatic Number Plate Recognition (ANPR)
* Engineered an autonomous traffic monitoring system featuring dynamic plate area extraction and continuous edge video inference.
* Achieved an audited **93.75% system processing accuracy** during real-world environment validation.
* *Stack:* OpenCV, Python, Raspberry Pi hardware deployment.

### Skin Cancer Detection (DC-YOLOv12-ELFEN)
* Advanced integration of state-of-the-art YOLOv12 and Dilated Convolution architectures optimized for pixel-level medical imagery diagnostics and skin lesion segmentation.
* *Stack:* Python, PyTorch, Advanced Computer Vision.

### Enterprise Data & AI Tools
* **English-to-SQL Generator:** Created an AI-powered natural language interface transforming English queries into accurate, schema-aware SQL statements using NLP techniques and MySQL.
* **Customer Purchase Behavior Analysis:** Performed intensive EDA and transaction data modeling to uncover key purchasing insights using Python, Pandas, and MySQL.
* **AI-Based Currency Recognition:** Designed an IoT prototype leveraging a Raspberry Pi setup for automated real-time physical currency identification.
